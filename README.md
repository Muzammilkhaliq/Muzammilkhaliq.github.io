# Muzammil Khaliq - Portfolio

All files sit in one folder, so you can upload everything at once.

1. In your GitHub repository click Add file > Upload files.
2. Select ALL files in this folder (Ctrl+A) and drag them in, or use "choose your files".
3. Click Commit changes.
4. Settings > Pages > Deploy from a branch > main > / (root) > Save.

To change content, edit the CONFIG block near the top of index.html.
To change your photo or CV, replace profile.jpg or Muzammil-Khaliq-CV.pdf with a new file of the same name.
